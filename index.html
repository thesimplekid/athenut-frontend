WebAssembly is required

Athenut runs entirely in your browser using WebAssembly, which appears to be unavailable. On iPhone, iPad, and Mac this is usually caused by Lockdown Mode, which disables WebAssembly.

If you trust this site, you can exclude it from Lockdown Mode:

  • In Safari, tap the page settings button (ᴀA) in the address bar and turn off Lockdown Mode for this website, then reload.
  • Or go to Settings → Privacy & Security → Lockdown Mode → Configure Web Browsing and add this site to the excluded websites.
